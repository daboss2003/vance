# Introduction

**Vance** is a fast, cross-platform video editor for macOS, Windows, and
Linux. It combines a professional non-linear editor (NLE) with a color page,
a Fairlight-class audio mixer, node-graph compositing, motion-graphics
titles, captions, and a set of AI-assisted tools — all in one application.

This manual covers installation, the first-run setup, and each major area of
the editor. You do **not** need to read it cover to cover: install Vance,
open a clip, and start editing. Come back here when you want to go deeper.

## What Vance can do

- **Edit** on a classic track timeline or a magnetic timeline with clip
  connections, ripple edits, roll/slip/slide trims, and version history with
  branching.
- **Grade** on a dedicated Color page with a node-based grading graph,
  scopes, LUTs, and a managed color pipeline (Rec.709, P3, Rec.2020, ACES).
- **Mix** with a full console: per-track channel strips, submix buses,
  inserts, and aux sends.
- **Composite** with a Fusion-style node graph and animated motion-graphics
  templates.
- **Caption** with tolerant SRT/VTT import/export and optional speech-to-text
  transcription.
- **Finish** by exporting to ProRes, DNxHR, H.264, HEVC, or AV1 — or
  publishing directly to YouTube.

## Conventions

- Menu paths look like **File ▸ Open**.
- Keyboard shortcuts look like <kbd>Space</kbd> (play/pause).
- Optional features that rely on a tool you install yourself are called out
  explicitly, with the command to install them.
